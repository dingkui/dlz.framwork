# 配置参考

## 核心模块

核心 `dlz-kit` 不读取 Spring Boot 配置文件，也不要求容器初始化。大多数能力通过构造器或静态 API 使用。

## Caller

`DlzCaller.getProperties()` 返回全局 `DlzCallerProperties`：

- `injectCallerMdc` 默认 `false`，需要显式开启才写入 Caller MDC；
- `ignoreCallerPackages` 默认为空，可添加需要跳过的公共组件包前缀。

```java
DlzCaller.getProperties().setInjectCallerMdc(true);
DlzCaller.getProperties().addIgnoreCallerPackage("com.example.client.");
```

## MyBatis SQL 日志插件

`DlzSqlLogProperties` 默认值为：`enabled=true`、`showCaller=true`、`showMapper=false`。插件没有 Spring Boot Starter；请创建属性对象并将 `DlzMybatisSqlLogInterceptor` 注册到 MyBatis 配置中。

## Jackson 插件

`JacksonUtil.getInstance()` 返回共享 `ObjectMapper`。插件默认允许单引号和裸字段名、忽略未知属性，并配置非空序列化和日期格式。需要独立配置时请自行创建 `ObjectMapper`，不要修改共享实例的全局配置。
