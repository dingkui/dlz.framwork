# 项目介绍

`dlz-kit` 是面向 Java 应用的轻量工具库，重点解决嵌套 JSON/Map 操作、类型转换、调用方日志和进程内缓存等重复问题。

当前发布模块：

- `top.dlzio:dlz-kit`：核心能力，Java 8 编译目标，核心 JSON 不依赖 Jackson 运行时。
- `top.dlzio:dlz-json-jackson`：可选 Jackson 互操作。
- `top.dlzio:dlz-caller-mybatis`：可选 MyBatis SQL 日志调用方插件。
