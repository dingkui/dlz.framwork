## Maven 依赖

在 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-kit</artifactId>
    <version>6.7.5</version>
</dependency>
```

最新版本查看：[Maven Central](https://search.maven.org/artifact/top.dlzio/dlz-kit)

---

## Gradle 依赖

```gradle
dependencies {
    implementation 'top.dlzio:dlz-kit:6.7.5'
}
```

Kotlin DSL：

```kotlin
dependencies {
    implementation("top.dlzio:dlz-kit:6.7.5")
}
```

---

## 依赖说明

核心模块运行时不依赖 Jackson，JSON 解析由内置实现提供。需要 Jackson 生态互操作时，再额外引入 `dlz-json-jackson` 插件。

需要 Jackson 互操作能力时，请显式加入插件依赖：`top.dlzio:dlz-json-jackson`。核心模块无需添加 Jackson 依赖。

```xml
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-json-jackson</artifactId>
    <version>6.7.5</version>
</dependency>
```

## 验证安装

```java
import com.dlz.kit.json.JSONMap;

public class InstallTest {
    public static void main(String[] args) {
        JSONMap map = new JSONMap("name", "张三", "age", 25);
        System.out.println(map.getStr("name"));  // 张三
        System.out.println(map.getInt("age"));   // 25
    }
}
```

## 常见问题

**Q: 项目没有 Jackson 怎么办？**
A: 不需要 Jackson。dlz-kit 默认使用内置 JSON；只有显式使用 Jackson 生态兼容能力时，
才按需引入 `top.dlzio:dlz-json-jackson`。

**Q: 支持哪些 JDK？**
A: JDK 8、11、17、21。

**Q: 需要配置文件吗？**
A: 不需要，开箱即用。
