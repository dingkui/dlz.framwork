# DLZ Kit 模块结构

## 最终结构

```text
dlz-kit-parent
├── dlz-kit
└── plugins
    ├── dlz-json-jackson
    ├── dlz-caller-mybatis
    ├── dlz-kit-spring        planned
    └── other integrations    planned
```

`dlz-kit-parent` 统一版本、依赖版本和构建插件，不作为业务功能依赖。

## dlz-kit

`top.dlzio:dlz-kit` 是一个可独立使用的轻量 Jar，包含：

- 字符串、集合、日期、缓存和基础反射工具；
- `JSONMap`、`JSONList`、内置 Parser/Writer/Path；
- 基础 Bean 和泛型类型转换；
- caller 解析、MDC 和上下文 scope。

运行时除 `slf4j-api` 外不引入第三方框架。内置 JSON 行为固定，不会因为 classpath
中出现 Jackson、Spring 或其他 JSON 库而自动更换实现。

```xml
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-kit</artifactId>
    <version>6.7.0</version>
</dependency>
```

## plugins

`plugins` 是只用于构建分组的 Maven 聚合 POM，不发布全量插件 Jar。每个插件都是
独立 artifact，用户按需引入；`dlz-kit` 永远不反向依赖插件。

### dlz-json-jackson

Jackson 生态兼容模块，提供 `JacksonUtil`、`ObjectMapper`、`JsonNode`、`JavaType`、
Jackson Module 和 JSONMap/JSONList 互操作。它不会自动替换 `dlz-kit` 的内置 Parser、
Writer、Path 或默认类型转换。

```xml
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-json-jackson</artifactId>
    <version>6.7.0</version>
</dependency>
```

### dlz-caller-mybatis

MyBatis SQL 日志插件，提供可执行 SQL、调用位置、完整执行耗时和影响行数。依赖
`dlz-kit` 的 caller 能力，MyBatis 使用 `provided` scope。

```xml
<dependency>
    <groupId>top.dlzio</groupId>
    <artifactId>dlz-caller-mybatis</artifactId>
    <version>6.7.0</version>
</dependency>
```

### 后续插件

`dlz-kit-spring`、HTTP Client、Redis Client 等模块只在有实际实现时加入 Reactor，
不创建空 Jar，也不进入 `dlz-kit` 的传递依赖。

## 依赖规则

```text
dlz-kit
    └── slf4j-api

dlz-json-jackson
    ├── dlz-kit
    └── jackson-databind

dlz-caller-mybatis
    ├── dlz-kit
    └── mybatis (provided)
```

禁止：

```text
dlz-kit -> plugin
dlz-kit -> Jackson
dlz-kit -> Spring
dlz-kit -> MyBatis
plugin -> another unrelated plugin
```
