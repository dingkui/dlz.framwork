# 兼容性、安全与限制

- 编译目标为 Java 8；发布前应按 CI 矩阵验证运行环境。
- 核心 JSON 与 Jackson 插件是两套实现，依赖应按模块显式选择。
- `JSONMap`、`JSONList` 是可变数据结构；多线程共享时由调用方负责同步。
- 路径写入会创建中间结构，动态路径来自外部输入时应先做白名单或格式校验。
- `ValUtil` 对缺失值可返回 null/默认值，对存在但非法的内容抛出异常。
- `MemoryCache` 是进程内缓存，不提供跨 JVM 一致性；缓存加载器和敏感数据需由调用方控制。
- MyBatis SQL 日志可能包含敏感参数，生产环境应配置日志级别、脱敏和访问权限。
- 性能、体积和覆盖率数字只有在可复现基线存在时才具有参考意义。
