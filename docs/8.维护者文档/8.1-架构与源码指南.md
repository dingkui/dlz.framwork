# 架构与源码指南

## 模块

- `dlz-kit`：核心 JSON、JSONMap/JSONList、转换、缓存、Caller 与通用工具。
- `dlz-json-jackson`：Jackson 适配层，不应反向成为核心模块运行时依赖。
- `dlz-caller-mybatis`：MyBatis SQL 日志插件，需要调用方完成注册。

## 修改路由

- JSON 语法和模式：`dlz-kit/src/main/java/com/dlz/kit/json/core`。
- JSONMap/JSONList：`dlz-kit/src/main/java/com/dlz/kit/json`。
- 转换与工具：`dlz-kit/src/main/java/com/dlz/kit/util`。
- 缓存：`dlz-kit/src/main/java/com/dlz/kit/cache`。
- 插件行为：对应 `dlz-kit-plugins/*/src/main/java`。

修改公共行为时，同时更新对应测试和 `docs/6.参考手册/6.1-公共API.md`；不要把 `public` 自动视为稳定 API，SPI 与实现细节需单独标注。
