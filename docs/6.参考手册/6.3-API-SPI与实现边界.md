# API、SPI 与实现边界

## 稳定使用面

面向普通调用方的主要入口包括：`JSONMap`、`JSONList`、`JsonUtil`、`ValUtil`、`ConvertUtil`、`ICache`、`MemoryCache`、`CacheUtil`、`CacheMap`、`DlzCaller` 和各插件的公开接入类。

## 高级与扩展面

`Json`、`JsonOptions`、`JsonFeature`、`JsonPath`、`JsonMapper`、`TypeRef`、`JsonTypes` 等公开类型用于高级解析、泛型和扩展场景。它们虽然是 `public`，但调用方应以源码 Javadoc 和测试为准，不应把实现细节当作长期兼容承诺。

## 实现细节

`InternalJsonMapper`、解析器/写入器内部类、Jackson 自定义反序列化器和缓存内部元素不属于稳定 API。不要在业务代码中直接依赖内部包或内部类。

## 暂不开放的方向

`JSONObject` 不是当前发布 API；该方向暂不开发、不开放，也不应出现在示例、Maven 坐标或兼容性承诺中。

精确方法签名见 [公共 API](6.1-公共API.md)，行为边界以源码和测试为准。
